FEATURES

Dark Mode
Full dark theme for Bogleheads forum pages and the side panel. Choose System (follows your OS light/dark setting), Light, or Dark from the theme selector at the top of the side panel. When set to System, the theme switches automatically when your OS theme changes.

Zebra Striping
Add alternating row colors to the topic list for easier reading. Choose any color you like.

Hide Read Topics
Automatically tracks topics you've clicked and lets you hide them. Topics reappear when new replies are posted, so you never miss new activity.

Unread Badge
Shows the count of unread topics on the extension icon. The badge color changes based on how many unread topics you have: green (1-20), yellow (21-60), or red (61+).

Highlight Hot Topics
Make popular topics stand out by highlighting topics above a customizable reply threshold. Choose your own highlight color.

Watch Posters
Keep an eye on your favorite posters. Add usernames via the side panel or right-click a poster's profile link on the forum to add them. Topics where a watched poster is the author or last poster are highlighted with a customizable color. Watched poster highlighting takes priority over hot topic highlighting.

Hide Old Topics
Filter out topics older than a specified number of days to focus on recent discussions.

Show Subforums
Show or hide topics from specific subforums on the active topics page. Each subforum has a checkbox in the side panel — uncheck any to hide those topics. All subforums are shown by default.

Adjustable Font Size
Increase or decrease the topic list font size from 50% to 200% for comfortable reading.

Mark as Read (Right-Click)
Right-click any topic row to mark it as read without opening it. Useful for clearing topics you're not interested in.

Mark All as Read
One-click button in the side panel to mark all visible topics on the current page as read. Useful for catching up quickly after time away.

New Replies Indicator
Shows a red dot next to topics you've previously read that have new replies since your last visit. Toggle this on or off from the side panel. Hover over the dot to see a tooltip confirming new replies are available.

Topic Muting
Right-click any topic row and select "Mute this Topic" to hide it from the active topics page. Muted topics stay hidden as long as the feature is enabled. Manage your muted topics in the side panel — see the full list and unmute any topic with the × button. Up to 20 topics can be muted at a time; when the limit is reached, the oldest muted topic is automatically removed and a brief notification appears. Toggle topic muting on or off from the side panel — when off, muted topics are still saved but not hidden.

Topic Bookmarks
Star any topic to save it for later. Bookmarked topics appear in the Bookmarks section at the top of the side panel so you can find them again, even after they leave the active topics page. Click a bookmark to navigate to the topic, or remove it with the × button.

Pointer Cursor
Enable a pointer cursor when hovering over topic rows to make them feel more clickable.

Compact Mode
Reduces row padding and line height in the topic list to fit more topics on screen. Toggle it on or off from the side panel.

Hide Left Sidebar
Removes the left navigation sidebar from the page to give more horizontal space to the topic list. When enabled, the table automatically gains left padding so content doesn't touch the edge. Toggle it on or off from the side panel.

Hide Page Banner
Hides the "Bogleheads.org – Investing advice inspired by John Bogle" title banner at the top of the page to reclaim vertical space. Toggle it on or off from the side panel.

Row Hover Effect
Topic rows subtly darken when you hover over them, giving a more interactive and modern feel. Always on — works with any stripe color.

Subforum Color Coding
Shows a colored 4px left border on each topic row based on its subforum. Each of the 11 subforums has a distinct color. The same colors appear as small squares next to each subforum name in the Show Subforums list. Hover over the colored border or the subforum letter to see the full subforum name as a tooltip. Toggle it on or off from the side panel.

Unread Count in Tab Title
The browser tab title shows the number of unread topics — for example, "Bogleheads (23 unread)". When all topics are read, it simply shows "Bogleheads". Always on, no toggle needed.

Time Tracking
See how much time you spend on Bogleheads.org. The side panel displays today's time, all-time total, and a sparkline graph showing your activity over the last 30 days. Reset anytime to start fresh.

Statistics
Track your reading habits with a Statistics section in the side panel. See your current reading streak (consecutive days with activity), topics read over the last 30 days with a bar chart, and your top 5 most-visited forums ranked by visit count. Reset statistics anytime.

Omnibox Commands
Type "bh" in Chrome's address bar, press Tab, then use these shortcuts:
• new - Go to active topics
• hot / hot off - Toggle hot topic highlighting
• zebra / zebra off - Toggle zebra striping
• font inc / font dec - Adjust font size
• reset - Clear read history
• #12345 - Go to topic by ID
• user:alice - Search posts by user
• "search term" - Search the forum

Keyboard Shortcuts
Use these shortcuts from any Bogleheads page:
• Alt+B - Toggle side panel
• Alt+Shift+H - Toggle hide read topics
• Alt+Shift+N - Navigate to active topics
• Alt+Shift+R - Mark current topic as read
Reassign shortcuts at chrome://extensions/shortcuts.

Export/Import Settings
Download your settings as a JSON file to back them up or transfer to another machine. Import a previously exported file to restore your settings.

Sticky Header
The page title, stats line, and column headers stay pinned at the top of the page while you scroll through topics, so you always know which column is which.

Clickable Rows
Click anywhere on a topic row to navigate to that topic — no need to hit the link text exactly. Existing links in the row (like poster names) still work normally.

Collapsible Side Panel Sections
Click any section header in the side panel to collapse or expand it. A chevron indicator shows the current state. Collapsed sections are remembered and sync across your Chrome browsers.

Side Panel

All controls live in Chrome's built-in side panel. Click the extension icon to toggle it. Click the "Better Bogleheads" header at the top of the panel to navigate to Bogleheads.org in the current tab. Settings apply immediately.

Helpful Tooltips
Hover over any setting in the side panel to see a description of what it does.

All settings are saved automatically and persist across sessions.

PRIVACY

This extension only runs on https://bogleheads.org/ and stores your preferences locally using Chrome's storage API. No data is collected or transmitted.

OPEN SOURCE

This extension is open source and available on GitHub. Contributions and feedback are welcome.
